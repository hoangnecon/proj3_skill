# sv-22 · Shots and camera (gate G5)

The narration is the clock. Every shot starts on a word (`at: 's4@bấm'`), every action lands on a word,
and cut rhythm follows the episode's pacing band in `standards/pacing.json`:
- **9:16 Shorts (`shots`):** `2.0–3.0 s` mean (`20–28 shots/min`, `p10 ≥ 1.2 s`, `max 6.5 s`, ~1 shot per `2.2 s` — the reference episode *Thang máy* has 67 shots in 153 s).
- **16:9 Long-Form (`shots_long_16x9`, `v5.4.0`):** `2.8–6.2 s` mean (`9.5–21.0 shots/min`, `p10 ≥ 1.3 s`, `max 9.5 s`, `SH-15` warns `> 8.0 s` → **~95–180 crisp multi-scale cinematic shots** for a 10-minute episode), alternating **`1.8–3.2 s` reaction close-ups, POV inserts & OTS cuts** with **`4.0–6.2 s` dynamic tracking/action shots**, guarded by **`SH-20`** (max 2–3 wide stage shots before cutting to a drawn `closeup`, `pov`, `insert`, or `fg` OTS shot!), **`MO-16`** (multi-action density on `> 5.0 s` takes), and **`MO-18`** (zero frozen creature attacks or `> 3.4 s` static actor holds).
An agent that puts a dead static frame per sentence or camps in unbroken dollhouse-wide shots has failed this skill.

## Read first
1. `references/shot-grammar.md` — benchmarks, shot sizes, camera moves, composition, scene templates.
2. `references/shotlist-api.md` — anchors, every ShotDef field, overlays, waivers.
3. sv-21 `references/actor-api.md` and `acting.md` — for everything actors do.
4. `src/exemplar/shotlist.thang-may.ts.txt` — the reference shotlist (v1 field names, see the migration table).

## Inputs → outputs
- In: G4 passed (cast, sets, geo), `beats.md` segment map, `src/data/words.json` (from G3).
- Out: `src/episode/shotlist.ts`, `qa/contact_p*.jpg` (Tier 1 Đại đoạn), `qa/contact_segments/seg_*.jpg` (Tier 2 Trung đoạn), `qa/shots/NN.jpg` + `qa/strips/*.jpg` (Tier 3 Tiểu đoạn 8-frame filmstrips with `Δ=%` pixel motion delta), `qa/motion_energy.json`, `qa/cards/NN.jpg`, `qa/review/NN.json`, `qa/shots.json`, `gates/G5.review.md`.

## Workflow
1. **Shot plan on paper first.** For each segment, list the words that need a picture (new person, place,
   object, action, twist, punch). Write them as a comment block at the top of each segment's section in
   shotlist.ts: `// s4: Tháng(tag, wide) · Hạnh(label, medium) · thú(bubble, push) · bấm(close, reach) · năm(insert)`.
   Target count: **narration seconds ÷ 2.2** for 9:16 Shorts (`shots`), or **~95–180 crisp multi-scale cinematic shots** (`2.8–6.2 s` mean, `9.5–21.0 shots/min`, `max 9.5 s`) for 16:9 Long-Form (`shots_long_16x9`), alternating `3.8–6.0 s` establishing/medium action takes (`MO-16`) with `1.8–3.2 s` drawn `closeup`/`pov`/`insert`/`fg` OTS cuts every 2–3 wide shots (`SH-20`).
2. **Write shots (with `qa.mjs place` zero-rework solver)** segment by segment. Before blocking actors/props on a set, run `node scripts/qa.mjs place <setId>` to print collision-free, `LA-01`-scaled, caption-safe floor slots and recommended camera bounds directly from the set geometry. Size from the grammar table, cam numbers from `qa.mjs place` + the set's grid plate (`qa/design/set_<id>_grid.png`), actors from sv-21 recipes, keys on words.
3. **Pre-Flight Zero-Bounce Gate (BEFORE any render!):** run `node scripts/lint.mjs shots` until **0 errors** (including `MO-10` locked-`face` `dx` reversal, `MO-13` invalid/impossible `pushTarget`, `MO-14` missing `SubjectSeat` or contradictory rider facing on mounted creatures, `MO-15` unknown `Actor.fx` keys, `MO-16` Long-Form `> 5.0 s` dead static holds with `0` choreography events, `MO-17` `arcH > 0` stretched across a path `> 1.85 s` without a bounded `<= 2.2 s` `legs: 'jump'` window — preventing mid-air walking and auto-queuing an 8-frame `jump takeoff/apex/land` strip, `MO-18` `SUBJECT` attack poses `pounce|charge|dive|attack` frozen in place `> 1.8 s` without a lunge `path`/follow-through, `GE-16` overlay covering > 55% of an actor's head, `GE-20` Hero Subject / flying creature occlusion `> 45%` ERROR / `> 25%` WARN + HOT — auto-queuing 8-frame `subject motion/occlusion` strips, `LA-01` set `actorScale` & `SUBJECT` `relToActor` scale ratios, `LA-02` 3×3 grid overcrowding `>= 4` clusters or `> 78%` union occupancy, `LA-03` fake close-up camera zoom `> 1.35×`/`1.45×` on `establishing`/`wide` sets, `LA-04` non-`fg` hero creature sliced `> 35%` off frame edge, `CA-07` `long_16x9` shot-size progression banning `> 65%` `establishing` wide-shot monotony, `CA-08` multi-waypoint `ShotDef.camKeys` (`[cx, cy, zoom, at][]`) schema, monotonic time order, world bounds & anti-jolt validation, `SH-18` recurring hero creatures lacking `SUBJECTS` multi-pose registration, `SH-19` `ShotDef.mood` enum validation across `default|morning|golden|danger|lab|flashback|dramatic`, and **`SH-20`** banning `>= 4` consecutive full-stage wide/medium shots `zoom <= 1.16` with zero close-up/POV/OTS breaks). Then resolve every geometry/camera/layout/motion warning — `SH-20` (`>= 3` consecutive wide/medium stage shots `zoom <= 1.16` without close-up/POV/OTS breaks), `SE-18` (pairing a flat 90° `cameraDir: 'top'` floorplan with horizon-rig `side`/`front` actors — use 3/4 elevated `angle: 'high'`, `cameraDir: 'front'|'left'|'right'`), `SH-15` (shot duration `> 8.0 s` on `long_16x9`), `MO-18` (actor standing static `> 3.4 s` without acting/talk/path beats, marks HOT), `CA-06` (180° axis / eyeline flip where the same 2 on-screen actors swap left/right screen order across consecutive same-location cuts without a neutral `wide`/`high`/`ots` bridge shot, marks HOT), `CA-07` (`closeup + insert < 10%` on `long_16x9`), `CA-08` (`camKeys` abrupt velocity spike / whip-pan warning), `LA-02` (crowded cell `>= 3` clusters or `> 65%` occupancy), `SH-19` (`mood: 'danger'` stacked with `night > 0.7` crushing visibility), `GE-10` (sign edge-clip), `GE-11` (actor/overlay/prop over sign), `GE-15` (prop edge-clip), `GE-16` (overlay `bubble`/`label`/`stamp`/`tag` covering > 20% of an actor's head), `GE-17` (z-aware foreground world prop/creature covering > 35% of an actor's head; mounted riders on `Actor.mount` are excluded), `GE-18` (consecutive wide-shot `cam[2] <= 1.15` cast continuity drop with 0 actors between populated shots on the same set), `GE-20` (Hero Subject / flying creature occlusion `> 25%` WARN + HOT), `MO-11` (reach behind facing / `arms:'raise'` walk), `MO-13` (`push` without `pushTarget`/`reach`, marks HOT on `long_16x9`), `MO-14` (2+ riders on a creature lacking `straddle: true` / `grip`, marks HOT), `MO-15` (fall/trip with zero `fx`/`shake`, or `fly`/`hover` extra missing `altitude`), `MO-16` (`long_16x9` shot `> 5.0 s` with `< 2` choreography events or `> 8.5 s` with `< 3` events), `MO-17` (bounded jump window & 8-frame jump strip), `GE-01`, `GE-04`, `GE-07` — using `node scripts/qa.mjs layout` and `node scripts/qa.mjs where <i>` before rendering a single frame. `lint.mjs shots` also writes `qa/layout_report.json` (verified clean by `sv_gate.py check G5`).
   - **Shot-scale alternation & anti-dollhouse editing (`v5.4.0`, `SH-20`, `SE-18`):** Never string together 3–4 full-stage wide/medium dollhouse shots (`zoom <= 1.16`). Every 2–3 wide/medium shots, cut to a Location Pack's dedicated drawn `closeup`, `pov`, or `insert` plate (`actorScale: [0.95, 1.25]`), a tighter medium-close reaction (`zoom > 1.16` on a `medium`/`closeup` plate, respecting `LA-03`), or a foreground `fg: true` Over-The-Shoulder shot (`SH-20`). On `angle: 'high'` plates, keep `cameraDir: 'front' | 'left' | 'right'` (3/4 elevated perspective) rather than `'top'` when staging horizon-rig `side`/`front` actors (`SE-18`).
   - **Multi-waypoint cinematic camera (`v5.2.0`, `ShotDef.camKeys`):** For dynamic `4.0–6.2 s` action/tracking takes, prefer `camKeys: [[cx, cy, zoom, at], ...]` over a single linear `cam → cam2` slide — smoothly tracking a character's run, pausing on a reveal, and pushing in on the reaction beat under one continuous shot (`CA-08`).
   - **Living micro-acting, 3D turnarounds, jump/airspace & anti-freeze physics (`v5.4.0`, `src/anim.ts`, `side.tsx`, `Film.tsx`, `MO-17..18`, `GE-20`):** Engine rigs provide continuous `livingIdle`, conversational `talkGesture`, `poseImpulse`, 3D `'3q'` stepped turnarounds (`|sx| >= 0.78`), and creature `poseU` spring-morph, but **every creature attack (`pounce|charge|dive|attack`) MUST lunge/follow through within `<= 1.8 s` and every actor MUST perform real acting/talk/path beats at least every `<= 3.4 s` (`MO-18`)**. Bind `Actor.arcH` to a bounded `<= 2.2 s` `legs: 'jump'` window (`MO-17`); set `altitude: 160..280` on flying `SUBJECTS` for elevated `+1200` airspace sorting (`GE-20`, `MO-15`); use `pushTarget` (`MO-13`), `fx`/`wind` (`MO-15`), and `SubjectSeat.straddle`/`grip` (`MO-14`).
   - **Atmospheric lighting & depth (`v4.4.0`):** Use `ShotDef.mood` (`'default' | 'morning' | 'golden' | 'danger' | 'lab' | 'flashback' | 'dramatic'`, validated by `SH-19`) for lightweight PAL-token atmospheric color grading and `ShotDef.dof: true` for subtle far-layer (`d = 0.5`) depth-separation haze behind midground actors. The engine paints static riso paper grain (`url(#grainPat)`) instead of per-frame `<feTurbulence>`, and `deliver.mjs` renders shot-aligned macro-blocks (`SV_CHUNK_FRAMES`, default `1050` frames ≈ 35 s) for fast G7 delivery.
   - **Staging pitfall checklist:** verify `flip: true` points `pointL`/`pointR` toward the subject (not off-screen); never reach behind `face` or walk with `arms: 'raise'` (`MO-11`); never air-push without `pushTarget`/`reach` (`MO-13`); never paste flat or opposite-facing riders on a creature (`MO-14`); always set `altitude` on `fly`/`hover` extras and `fx`/`shake` on falls (`MO-15`); always bound `arcH > 0` jumps inside a `<= 2.2 s` `legs: 'jump'` window (`MO-17`); never freeze a creature mid-`pounce`/`charge`/`dive`/`attack` `> 1.8 s` or leave an actor static `> 3.4 s` (`MO-18`); break wide-shot streaks every 2–3 shots with a `closeup`/`pov`/`insert`/`fg` OTS cut (`SH-20`); avoid `cameraDir: 'top'` with `side`/`front` actors (`SE-18`); verify flying Hero Subjects stay unobstructed (`<= 25%`, `GE-20`); animate vehicle `x` (or set `keys`) whenever narration says a vehicle moves/rolls out; keep 2-actor screen left/right order consistent across dialogue cuts or insert a neutral `wide`/`high`/`ots` bridge shot (`CA-06`); avoid stacking `mood: 'danger'` with `night > 0.7` (`SH-19`).
4. **Single-Bundle 3-Tier Hierarchical Contact Sheet & Pixel Motion-Energy Pass (`qa.mjs pass`):** run `node scripts/qa.mjs pass changed` (or `node scripts/qa.mjs pass all` only if forcing a full re-render). Under ONE Remotion bundle and ONE browser session, it renders all **3 Mandatory Hierarchical Contact Sheet Tiers**, computes **`qa/motion_energy.json`**, renders cards/crops, runs `carry.py`, and invokes `scripts/blind_pack.mjs`:
   - **Tier 1 — Đại đoạn (`qa/contact_p<N>.jpg`):** Episode overview pages rendering **4 frames per shot** (`12%, 38%, 64%, 88%`) for shots `> 4.0 s` and **2 frames** for fast `<= 4.0 s` shots (changed shots carry a ●).
   - **Tier 2 — Trung đoạn (`qa/contact_segments/seg_<NN>_<loc>.jpg`):** Per-location / per-scene sequence contact sheets (also runnable standalone via `node scripts/qa.mjs segments`) to check scene rhythm, shot-scale alternation (`SH-20`), spatial continuity, and lighting consistency across consecutive cuts.
   - **Tier 3 — Tiểu đoạn (`qa/shots/<NN>.jpg` + `qa/strips/<name>.jpg`) & Pixel Motion-Freeze Detector (`qa/motion_energy.json`):** Automatic **8-frame `4×2` action filmstrip** (`qa/shots/<NN>.jpg`, also runnable via `node scripts/qa.mjs shotstrips` or `node scripts/qa.mjs shot <i>`) for EVERY dynamic/long/HOT shot — stamped with per-frame **`Δ=%` active-canvas pixel motion delta** from **`qa/motion_energy.json`** (warning whenever `frozen_streak >= 2` consecutive frame pairs freeze!) — alongside 8-frame action strips (`qa/strips/<name>.jpg`) for every queued walk, jump (`MO-17`), flying subject (`GE-20`), reach, ride, and set key, plus `cards/*.jpg` and `crops/*.jpg` for HOT shots with `crops_ok === false`.
   - `scripts/blind_pack.mjs` emits `qa/blind_review/{manifest.json, slice_1.json, slice_2.json, slice_3.json, RUBRIC.md}` wiring `shot_strip` (`qa/shots/<NN>.jpg`) into every dynamic/long/HOT slice entry (cryptographically covered by `blind_sha`), with enriched layout metrics (3×3 occupancy, scale/cutoff flags, `shotScale`, `set_streak`) and the **Pasted-Sticker Anti-Pattern Check** under `acting` and `contact`.
5. **Inspect All 3 Contact Tiers & `qa/motion_energy.json`:** open EVERY Tier-1 `qa/contact_p*.jpg` (~300 KB; changed shots carry ●), EVERY Tier-2 `qa/contact_segments/seg_*.jpg`, EVERY Tier-3 `qa/shots/NN.jpg` (`Δ=%` motion energy, zero `frozen_streak >= 2`) + `qa/strips/*.jpg` (8 full frames, `4×2` / 2 rows, sv-21 checklist). Look at shot-scale alternation, continuity, jump/flight physics, human-scale proportions, and design sheets.
6. **Per-shot blind review (3-way slices + `blind_sha` + mandatory `shot_strip`/`strips` anti-bypass protocol)** — `references/review-cards.md`. Three independent REVIEWERS who did not build the shots each take one slice (`qa/blind_review/slice_1.json`, `slice_2.json`, `slice_3.json`) plus `qa/blind_review/RUBRIC.md`. Reviewers judge ONLY from the rendered images (`card`, `shot_strip`, `crop`, `contact_page`, `strips`) and `narration` in their slice — never `shotlist.ts` or coordinates — check all items (8 base checks on 9:16; 10 checks `+ framing`, `+ variety` on `long_16x9`), and write batches via `node scripts/qa.mjs review --batch <batch.jsonl>` including each shot's `"blind_sha"` verbatim. Both `qa.mjs review --batch` and `sv_gate.py check G5` / `pass G5` reject any review missing or mismatching `blind_sha` against `qa/blind_review/manifest.json` **OR missing `"shot_strip"` / `"strips"` in `looked` on dynamic/long/HOT shots (zero blind review!)**.
   **After any later change** (a fix, a helper edit, a re-made voice): run `node scripts/qa.mjs pass changed` BEFORE briefing reviewers. It re-bundles once, updates only changed Tier-1/Tier-2/Tier-3 sheets, cards, crops, and strips, runs `scripts/carry.py` (keeping pixel-identical and valid retimed reviews), and prints the exact `qa/carry.json` re-review list.
   **Episode reviewed under v3.6** (every hash changes once on upgrade): FIRST `node scripts/qa.mjs adopt`, THEN `node scripts/qa.mjs pass all`.
7. **Fix loop** (only the shots marked `fix`): change → `node scripts/lint.mjs shots` + `node scripts/qa.mjs where <i>` → `node scripts/qa.mjs pass changed` (or `qa.mjs shot <i>` for a quick 1-shot 8-frame check, then `pass changed` before handing to reviewers). At most 3 tries per shot, then escalate (re-stage the shot or ask the user). A full `pass all` at most twice per episode.
8. **Review file** `gates/G5.review.md`: a line per contact page, segment contact sheet, and strip (≥ 4 words of what you saw),
   waivers justified, plus the cross-check: the conductor re-opens ≥ 10 % of the cards/8-frame shot strips at random (all HOT
   ones included) and names them.
9. **Gate**: `python3 scripts/sv_gate.py pass G5`. It reads every `qa/review/NN.json`: present, made for the
   shot's CURRENT hash (or carried to it — the gate re-checks every carry from the snapshots), reviewer ≠
   builder, all checks ok, `blind_sha` matches manifest (including `shot_strip`), `looked` includes `"shot_strip"` or `"strips"` on dynamic/long/HOT shots, and crops opened for HOT shots. (G5 needs no user
   approval; showing the user a contact page is still a good idea on the first episode of a series.)

## Rules
- Cut on words, never on seconds. Numbers are only for offsets inside a shot.
- First shot in every set is an establishing frame (k ≤ 1.2).
- Camera moves need a reason (push = tension, pull = reveal, follow = walk, tilt = height, drift = hold).
- The world never shows its edge (CA-05) and the caption band stays clear (OV-03).
- Every shot has life: a move, an expression change, a gesture, a key, or a moving set element.
- If the voice changes (G3 re-run), anchors move: re-run lint and contact; G5 goes stale automatically.
- A visual-only fix (pose, prop, set detail, camera) does not change `qa/timing.json`, so the mix (G6) stays
  valid; only a fix that moves cut times or keys sends you back to the mix.
- Open the light JPEGs (`*.jpg`, `_v.jpg`), never the multi-MB PNG masters, unless you zoom into one spot.
- Do not touch cast or set code in this phase; if a design is wrong, go back to sv-20 (G4 re-opens).

## Failure → fix
| You see | Do |
|---|---|
| Lint AN-01 word not found | the aligner split or spelled it differently; check words.json for that segment |
| Shot too short (SH-14) | merge into the neighbour or move the anchor one word later |
| Pacing off (`PC-01..03`, `SH-15`, `standards/pacing.json`: 9:16 Shorts `shots` = `2.0–3.0 s` mean, `20–28 shots/min`, `p10 ≥ 1.2 s`, `max 6.5 s`; 16:9 Long-Form `shots_long_16x9` = `2.8–6.2 s` mean, `9.5–21.0 shots/min`, `p10 ≥ 1.3 s`, `max 9.5 s`, `SH-15` warn `> 8.0 s`) | for Shorts: split long holds or merge flash cuts to land near `2.2–2.8 s`; for Long-Form: target `95–180` crisp multi-scale shots alternating `4.0–6.2 s` dynamic action/tracking takes (`MO-16`) with `1.8–3.2 s` reaction close-ups & POV inserts (`SH-20`), splitting any hold `> 8.0 s` (`SH-15`) |
| Same frame twice in a row | change size ≥ 1.3× or change subject; or drop one shot |
| Dollhouse wide-shot streak (`SH-20`) | `>= 3` (WARN) / `>= 4` (ERROR) consecutive full-stage wide/medium shots (`zoom <= 1.16` with zero close-up/POV/OTS breaks): cut in every 2–3 wide shots to the Location Pack's dedicated drawn `closeup`, `pov`, or `insert` plate (`SetDef.shotScale`), tighter reaction framing (`zoom > 1.16` on a `medium`/`closeup` plate), or a foreground `fg: true` OTS shot |
| Flat 90° floorplan perspective clash (`SE-18`) | never pair `cameraDir: 'top'` with horizon-rig `side`/`front` actors; switch to a 3/4 elevated `angle: 'high'` set (`cameraDir: 'front'\|'left'\|'right'`) or redraw the set in 35–45° perspective in sv-20 |
| Empty-looking frame | wrong cam centre (check the grid plate) or the set lacks detail there (back to sv-20) |
| Actor cut by the frame edge during an action (SZ-02) | move cam/cam2 toward the actor or block the action nearer the centre |
| Character tiny while talking (SZ-01) | push to medium (k 1.3–1.8) or scale s up to 1.1 |
| World edge visible (CA-05) | reduce the move or the zoom-out; or extend the set and its `bounds` in sv-20 |
| 180° axis flip (`CA-06`) | preserve left/right screen order of the 2 actors across same-location cuts, or insert a neutral `wide`/`high`/`ots` bridge shot |
| Wide-shot monotony / few close-ups (`CA-07`) | keep `establishing` sets `<= 65%` of `long_16x9` shots and add `>= 10%` drawn `closeup`/`insert` sub-scene plates for emotional beats |
| Bad `camKeys` choreography (`CA-08`) | give `ShotDef.camKeys` `>= 2` valid `[cx, cy, zoom, at]` waypoints with strictly ascending `at` times, keep every waypoint inside `SetDef.bounds` & `LA-03` zoom caps, and spread fast pans/zooms across `>= 0.6 s` |
| Action happens between words | anchor the reach/key to the word: `'s6@bấm+0.05'` |
| Contact sheet reads but the story does not | you missed a beat: re-read beats.md, add the insert/reaction shot |
| Scale mismatch (`LA-01`) | match actor `s` to the set's `actorScale [minS, maxS]` and Hero Subject scale to `relToActor [minR, maxR]`; inspect via `node scripts/qa.mjs layout <i>` |
| Cluttered frame (`LA-02`) | spread subjects across distinct 3×3 grid cells (`A1..C3`), attach riders with `Actor.mount` (counted as one cluster), or split dense beats into 2 shots (`< 4` clusters/cell, `<= 78%` occupancy) |
| Fake close-up zoom (`LA-03`) | never zoom an `establishing`/`wide` set past `1.35×` (`cam2 > 1.45×`); cut to a dedicated `medium` or `closeup` sub-scene plate (`SetDef.shotScale`) |
| Awkwardly sliced hero creature (`LA-04`) | re-frame creature inside the canvas (`<= 35%` edge clip), switch to a dedicated closeup pose, or mark `fg: true` if intentional foreground framing |
| Static creature reuse (`SH-18`) | register recurring creatures/bosses/vehicles in `src/episode/subjects.tsx` (`SUBJECTS`) with `>= 4` poses (`PR-06`) and vary `pose` across shots |
| Invalid or over-dark mood (`SH-19`) | use one of `default\|morning\|golden\|danger\|lab\|flashback\|dramatic` on `ShotDef.mood`; keep `night <= 0.7` when using `mood: 'danger'` |
| Air-pushing / unreachable push (`MO-13`) | supply `pushTarget: [tx, ty]` (or `reach`) within real arm reach (`<= 280 * H * s * 1.15`) whenever using `p: 'push'` or `legs: 'push'` |
| Flat or opposing mounted riders (`MO-14`) | add `straddle: true`, `grip: [gx, gy]`, and `wind` on `SubjectSeat`, verify seat exists, and match all riders' `face` to travel direction |
| Weightless fall / flying creature without shadow (`MO-15`) | validate `fx` keys (`dust\|sweat\|speed\|impact\|stars`), add `fx: ['impact', 'stars']` or `['dust']` on falls/trips, and set `altitude: 160..280` on `fly`/`hover` extras |
| Dead or sparse Long-Form shot (`MO-16`) | on `long_16x9`, every shot `> 5.0 s` needs `>= 1` (ERROR if `0`) and target `>= 2` choreography events (`>= 3` for `> 8.5 s`): layer motivated `cam2`/`camKeys`, set `keys`, `path`/`arcH`/`mount`/`pushTarget`/`reach`, keyed `p`/`e`/`view`/`face`/`legs`/`arms`, `fx`/`wind`, or animated `extras` |
| Stretched jump arc / mid-air walking (`MO-17`) | never stretch `arcH > 0` across a path `> 1.85 s` without a bounded `legs: [..., ['jump', t0], ['run'\|'walk', t1]]` window (`<= 2.2 s`); `PersonSide` plays 4-stage `jumpPhase` takeoff/apex/land and `lint.mjs` auto-queues an 8-frame jump strip |
| Frozen mid-attack creature or static actor statue (`MO-18`) | follow through every `SUBJECT` `pounce\|charge\|dive\|attack` pose with a lunge `path` or recovery pose within `<= 1.8 s` (ERROR if frozen `> 1.8 s`), and give every standing actor acting/talk/path/keyed `p`/`e` beats at least every `<= 3.4 s` |
| Low `Δ=%` / `frozen_streak >= 2` in `qa/motion_energy.json` | inspect `qa/shots/<NN>.jpg` `Δ=%` badges: add actor `path`, `talk`, keyed `p`/`e`/`view`, animated `extras`, set `keys`, or motivated `camKeys`/`cam2` (or split the hold into a `closeup`/`pov` reaction cut per `SH-20`) |
| Flying Hero Subject occluded (`GE-20`) | ensure flying `SUBJECT` declares `altitude > 20` (elevated `+1200` airspace above `mid` props), keep foreground occlusion `<= 25%` (`> 45%` ERROR, `> 25%` WARN + HOT), and inspect the auto-queued 8-frame `subject motion/occlusion` strip |
| `qa.mjs review --batch` or G5 rejects `looked` | for every dynamic/long/HOT shot, open its Tier-3 8-frame `qa/shots/<NN>.jpg` (`"shot_strip"`) or `qa/strips/<name>.jpg` (`"strips"`) and record `"shot_strip"` or `"strips"` in `looked` alongside verbatim `blind_sha` |
